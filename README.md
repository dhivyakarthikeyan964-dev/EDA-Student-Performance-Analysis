# EDA Student Performance Analysis

## Project Description

This project performs Exploratory Data Analysis (EDA) on a student performance dataset using Python. The analysis examines study hours, attendance, previous marks, and final marks to understand patterns and relationships in student academic performance.

## Dataset

The dataset contains 30 student records with 4 features:

- Study Hours
- Attendance
- Previous Marks
- Final Marks

## Analysis Performed

- Dataset inspection
- Data type analysis
- Missing value detection
- Duplicate value detection
- Statistical summary
- Data distribution analysis
- Scatter plot analysis
- Correlation analysis
- Correlation heatmap

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Visualizations

The project includes the following charts:

1. Study Hours Distribution
2. Attendance Distribution
3. Final Marks Distribution
4. Study Hours vs Final Marks
5. Previous Marks vs Final Marks
6. Correlation Heatmap

## Key Findings

The analysis shows strong positive relationships between study hours, attendance, previous marks, and final marks.

The correlation between Previous Marks and Final Marks is approximately 0.9994, indicating a very strong positive relationship in this dataset.

## Conclusion

The EDA helps identify important patterns in student academic performance and provides useful insights that can support further predictive modeling and analysis.
